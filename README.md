# kaida.github.io — PUBLIC SITE ONLY

Upload the **contents of this folder** to the root of the `kaida.github.io` repository.

Before publishing, edit `config.js` and set:
- `API_URL` to the deployed Google Apps Script Web App `/exec` URL.
- `FINANCE_WHATSAPP` to the KAIDA Finance number using international digits only.

Open Graph image: `assets/img/og-image.png` (1200x630).

Do not copy member data, payment records, tokens, or the private workbook into this repository.
